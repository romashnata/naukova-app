# naukova — сценарний аналіз вразливості та резильєнтності синтетичної мережі

## Скопіювати у свій репозиторій

Програма реалізує методику з пакета документів «НАУКОВА» (файли 01–72) для двох версій мережі —
Baseline (30 вузлів) і Corrected (35 вузлів, резервні N31–N35).

## Запуск

```
pip install openpyxl
python -m naukova                      # звіт у консоль
python -m naukova --out results.xlsx   # + таблиці в Excel
python -m naukova --param-set High     # Low | Base | High
python -m unittest discover tests      # звірка з еталонними значеннями документів
```

## Що обчислюється

| Модуль | Зміст | Документи |
|---|---|---|
| `network.py` | завантаження вузлів і зв'язків з xlsx | 09, 22 |
| `reach.py` | **Рівень 1**: строгі рольові підграфи (BFS) і матриця 108 рольових сценаріїв (9 ролей × 6 цілей × 2 версії) | 30, 37, 38, 41, 42–59 |
| `compromise.py` | **Рівень 2**: пошук рольово допустимих маршрутів у графі, `V`, `R`, `S`, `B = R·(1−V)`, `C_VR = ΔV/ΔR`; спільні фактори (вхід, ціль) враховуються один раз | 47, 60–68, 71 |
| `analysis.py` | аналіз чутливості (Low/Base/High), перевірка стійкості висновку | 67, 68 |
| `failure.py` | стани відмови FS00–FS10, `R_fail`, `V_fail`, 24-годинні time-weighted proxy | 72 |
| `params.py` | усі синтетичні параметри та визначення сценаріїв PC01–PC05 | 62–72 |

Маршрути не задаються вручну: програма знаходить їх у мережі (наприклад, N13→N14→N17 і
N13→N32→N17 для PC03 у Corrected), а ймовірності переходів бере за значенням `access_roles` ребра.

## Результат на синтетичних даних (Base)

PC03–PC05: `R` 0,855 → 0,979, `V` зростає на 14,5 %, `B` покращується; знак ефекту
стійкий у 9 з 9 комбінацій (відносний приріст `V` від 2,98 % до 36,25 %).

## Обмеження

Усі ймовірності — синтетичні модельні параметри, а не емпіричні частоти; 24-годинні показники —
time-weighted proxy, а не ймовірність інциденту. `B` і `C_VR` — пілотні показники в межах моделі.
